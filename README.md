An intuitive and efficient personal desktop wallet application designed to help users take control of their finances by tracking income sources, monitoring expenses, and automatically updating remaining balances.

---

# Overview

The Personal Finance Management System acts as a smart digital wallet. Users can deposit funds, log daily expenditures, and categorized transaction details to maintain full visibility over where their money goes. By keeping a structured record of all financial movements, it provides clear clarity on total income, total spending, and the current net balance.

---

# Key Features

*  **Personal Financial Management:** Easily record and manage daily financial activities.
*  **Income Source Tracking:** Log incoming funds along with their respective sources.
*  **Expense Source Tracking:** Track expenditures and identify major spending habits.
*  **Real-Time Balance Calculation:** Automatically calculates and displays the current available balance in your wallet.
*  **Simple & User-Friendly GUI:** Clean interface built with Java Swing for smooth navigation and ease of use.
